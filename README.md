# PS with Python

## 소개

Python을 활용한 알고리즘 및 코딩 테스트 문제 풀이를 정리한 저장소입니다.

백준(BOJ), 프로그래머스, SWEA 등 다양한 온라인 저지의 문제를 해결하며 작성한 코드를 보관하고 있으며, 문제 해결 능력 향상과 알고리즘 학습을 목적으로 합니다.

## 주요 내용

* 자료구조 (Stack, Queue, Heap, Tree 등)
* 정렬 및 탐색 알고리즘
* 그래프 탐색 (DFS, BFS)
* 동적 계획법 (DP)
* 그리디 알고리즘
* 구현 및 시뮬레이션 문제
* 기타 코딩 테스트 대비 문제 풀이

## 폴더 구조

```text
PSwithPython/
├── BOJ/
├── Programmers/
├── SWEA/
└── 기타 문제풀이/
```

각 디렉터리에는 문제 번호 또는 문제 이름 기준으로 풀이 코드가 정리되어 있습니다.

## 사용 방법

### 저장소 클론

```bash
git clone https://github.com/kikointheworld/PSwithPython.git
cd PSwithPython
```

### 실행

```bash
python 문제파일명.py
```

예시:

```bash
python 1000.py
```

## 개발 환경

* Python 3.x

* Python 문법 및 활용 능력 향상
